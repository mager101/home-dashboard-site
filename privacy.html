Privacy policy

Home Dashboard · last updated September 2026

Home Dashboard is a private, self-hosted application used by one person for their own household. It has no other users, no sign-ups, and no hosted version. This policy describes what the application does with data, and in particular with data it reads from Google.

Who runs it

The application is built and operated by a single individual on hardware they own. There is no company, no team and no third-party operator.

What data it handles

  • Financial records entered by the owner: transactions, budgets, categories and merchants.
  • Calendar entries, saved places and routes.
  • A personal media watch list.
  • Bank transaction alert emails read from the owner's own Gmail account, when that feature is enabled.

Google account data

The application requests one Google scope, gmail.readonly, and only from the owner's own account.

What it does with it. It periodically checks for new bank transaction alert emails, extracts the amount, merchant and timestamp, and stores those as pending entries for the owner to accept or reject. Messages that are not bank alerts are ignored and nothing is recorded about them.

What it cannot do. The scope is read-only. The application cannot send email, cannot delete or modify email, cannot change mailbox settings, and has no access to any other Google service.

Where it goes. Message contents are stored only in the owner's own database, on the owner's own server. Original message text is retained so that incorrectly read messages can be diagnosed and corrected.

What it does not do

  • No data is sold, rented, shared or disclosed to anyone.
  • No data is transferred to any third party, and no third-party analytics, advertising or tracking is used.
  • No data is used to train any machine learning or artificial intelligence model.
  • There is no server operated by anyone other than the owner. Nothing is uploaded anywhere.

Google user data is used solely to provide the transaction capture feature described above, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

Where data is stored, and for how long

All data lives in a PostgreSQL database on the owner's own machine, on a private home network. It is retained for as long as the owner finds it useful and is deleted by the owner at will.

Security

The application runs on a private network and is not exposed to the public internet. Credentials are held in the server's environment rather than in the database. Access to the application requires a password.

Revoking access

Google access can be withdrawn at any time from the Google account permissions page. Revoking it stops the application reading any further mail immediately.

Children

The application is not directed at children and is not available to the public.

Changes

If this policy changes, the revised version will be posted on this page with an updated date.

Contact

Questions about this policy can be sent to the address shown on the application's Google consent screen.
