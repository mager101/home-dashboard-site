Home Dashboard

A self-hosted personal dashboard. Budgeting, calendar, maps and media tracking, running on one person's own server.

What it is

Home Dashboard is a private application built and run by one person for their own household. It is not a product, not a service, and not available to sign up for. There is no hosted version and no public instance.

What it does

  • Records income and expenses, and reports on them by month, year, category and merchant.
  • Tracks budgets, recurring payments and subscriptions.
  • Holds a shared household calendar and a set of saved places and routes.
  • Keeps a personal watch list for films and television.

Why it asks for Gmail access

Recording every transaction by hand is tedious and easy to forget. The budgeting side of the app can read bank transaction alert emails and turn them into pending entries for the owner to review, so spending is captured without being typed in.

Access is read-only. The app requests only the ability to read mail. It cannot send mail, cannot delete mail, and cannot change anything in the mailbox. It looks for bank alert messages and ignores everything else.

How the app handles data is set out in the privacy policy.
